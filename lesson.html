الحروف الخاصة بالألماني

الحروف دي مش موجودة في الإنجليزي: النقطتين فوق الحرف اسمهم Umlaut.

  • زي «إيه» بس الصوت مفتوح شوية.
    مثال: = بنت
  • قولوا «إيه» وانتو مدوّرين شفايفكم.
    مثال: = حلو
  • قولوا «إي» وانتو مدوّرين شفايفكم كأنكم هتقولوا «أو».
    مثال: = باب
  • اسمه Eszett، وبيتنطق «س» قوية زي ss.
    مثال: = شارع

أصوات مهمة

الحروف دي لما تيجي مع بعض بتعمل صوت مختلف، وهي اللي بتلخبط أغلب المتعلمين.

  • ch
    بعد a / o / u بتتنطق «خ».
    مثال: = كتاب
  • ch
    بعد e / i / ä / ö / ü بتتنطق «ش» خفيفة جدًا، زي الهمس.
    مثال: = أنا
  • sch
    بتتنطق «ش».
    مثال: = مدرسة
  • ei
    بتتنطق «آي».
    مثال: = لأ
  • ie
    بتتنطق «إي» طويلة.
    مثال: = أربعة
  • eu / äu
    بتتنطق «أوي».
    مثال: = ألماني
  • w
    بتتنطق «ڤ»، مش «و».
    مثال: = عالم
  • v
    غالبًا بتتنطق «ف».
    مثال: = أب
  • z
    بتتنطق «تس».
    مثال: = وقت
  • j
    بتتنطق «ي».
    مثال: = أيوه
  • s
    قبل حرف متحرك بتتنطق «ز».
    مثال: = سبعة
  • st / sp
    في أول الكلمة بتتنطق «شت» و«شپ».
    مثال: = مدينة، = رياضة
  • r
    بتطلع من الزور، قريبة من «غ» خفيفة.
    مثال: = أحمر

جرّبوا تقولوا

اسمعوا الكلمات دي وقولوها بصوت عالي.

  • شكرًا
